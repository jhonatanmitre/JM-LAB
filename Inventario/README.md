# Inventario

Inventory system for a small store, built step by step to learn Java.

## Roadmap

- [x] **v1 – Console:** add products, list, sell with ITBMS (7%), low-stock alert
- [ ] **v2 – OOP:** `Producto` and `Venta` classes, save data to a CSV file
- [ ] **v3 – Database:** MySQL/PostgreSQL with JDBC
- [ ] **v4 – API:** Spring Boot REST API

## Run

```bash
cd src
javac Main.java
java Main
```
